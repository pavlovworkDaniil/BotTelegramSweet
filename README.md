# Telegram Movie Bot

Телеграм-бот на Python, который показывает пользователю список фильмов из
локальной папки на сервере и отправляет выбранный файл прямо в чат.

## Что умеет

- Показывает список фильмов по команде `/movies`.
- Даёт выбрать фильм через inline-кнопки.
- Отправляет выбранный файл в Telegram.
- Позволяет обновить список файлов кнопкой `🔄 Обновить список`.
- Ограничивает отправку слишком больших файлов (лимит Telegram Bot API).

## Требования

- Python 3.10+
- Токен Telegram-бота от [BotFather](https://t.me/BotFather)

## Установка и запуск

1. Установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. Укажите переменные окружения:

   ```bash
   export TELEGRAM_TOKEN="<ваш_токен>"
   export MOVIES_DIR="/путь/к/папке/с/фильмами"
   ```

   Если `MOVIES_DIR` не задан, бот использует папку `./movies` относительно
   директории запуска.

3. Запустите бота:

   ```bash
   python bot.py
   ```

## Поддерживаемые форматы

`mp4`, `mkv`, `avi`, `mov`, `wmv`, `flv`, `webm`, `mpeg`, `mpg`, `m4v`.

## Команды

- `/start` — приветствие и открытие списка фильмов.
- `/movies` — показать фильмы из папки.
- `/help` — справка по боту.

## Проверка

```bash
python -m compileall bot.py
```
